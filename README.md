# HR Employee Attrition Analysis

This repository contains data analysis and machine learning models built on the **IBM HR Employee Attrition Dataset** (`WA_Fn-UseC_-HR-Employee-Attrition.csv`).  
The project explores the factors contributing to employee attrition and predicts the likelihood of an employee leaving the organization.

---

## 📊 Dataset
The dataset includes demographic, job-related, and performance data of employees.  
**File:** `WA_Fn-UseC_-HR-Employee-Attrition.csv`

**Key Columns:**
- `Age`
- `BusinessTravel`
- `Department`
- `DistanceFromHome`
- `EducationField`
- `Gender`
- `JobRole`
- `MaritalStatus`
- `MonthlyIncome`
- `OverTime`
- `Attrition` (Target variable)
